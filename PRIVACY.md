# Privacy and image notes

## Published material

This showcase contains a product description, a case study and one presentation image. It does not include application source code, production Git history, credentials, database exports, customer documents or private correspondence.

## Image selection and treatment

Public English homepage presenting AI Agency Company and its positioning across Europe and Africa.

A public service platform needs editorial consistency across languages and a clear separation between visitor content and administration. This showcase presents the public experience only; it contains no CMS access, backend functions, configuration or customer data.

The image was created from a real site capture on 26 November 2026. An image-editing tool was used to remove browser chrome and, where applicable, obscure sensitive fields. Retouching can introduce minor visual differences. The image illustrates the product; it is not a forensic screenshot or an exact representation of every interface detail.

Only the reviewed final JPEG is included. Original browser captures and intermediate files are not part of this repository. The application may evolve after the capture date.
